# Sybarites World — сайт питомника

## Запуск на Windows
1. Распакуйте ZIP целиком.
2. Откройте папку Sybarites-World в VS Code (в ней должен быть package.json).
3. Установите Node.js 20.9 или новее, если его нет.
4. В терминале выполните `npm install`, затем `npm run dev`.
5. Откройте http://localhost:3000.

Можно также запустить файл START.bat двойным щелчком.

## Где что находится
- app/page.jsx — главная страница.
- app/layout.jsx — общая оболочка и SEO.
- app/globals.css — общие стили.
- components/sections — HTML-разделы в порядке отображения.
- public/images — фотографии.
- public/videos — сюда добавлять видео (список в README.txt).
- public/js/site.js — языки, каталог, галерея и контакты.
- package.json и конфигурации — служебные файлы, не удалять.

## Ограничения
Видео отсутствуют. Номер WhatsApp 34600000000 — заглушка. Некоторые изображения внешние. Сборка и внешний вид в браузере не проверены. Исходный HTML сохранён внутри Next.js.
